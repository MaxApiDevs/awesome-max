# Awesome MAX
Лучшие полезные сервисы и технологии MAX для эффективной разработки под макс мессенджер.

### MaxMessengerAPI.ru
Swagger для прямого тестирования эндпоинтов MAX.
- **Быстрые тесты:** Закидываешь JSON в Postman или в современную IDE (VS Code, PyCharm, WebStorm) и сразу дёргаешь любые эндпоинты.
- **Написание кода:** Скармливаешь этот JSON в IDE или OpenAPI Generator и получаешь готовый базовый SDK на любом языке за секунду без рутины.
- **Абсолютная прозрачность:** Все схемы, лимиты и скрытые поля как на ладони, без необходимости ковырять скомпилированный JS документации.
